## 📖 Overview

**Stella**는 플레이어가 별을 수집하며  
다양한 이야기와 선택을 경험하는  
스토리 중심의 개인 프로젝트입니다.

> **"한 편의 이야기를 플레이한다."**

라는 경험을 목표로 제작했습니다.

---

## ✨ Features

| Feature | Description |
|---------|-------------|
| ⭐ Star Collection | 별 수집 시스템 |
| 💬 Dialogue | NPC 대화 시스템 |
| 📚 Story | 스토리 진행 |
| 🎬 Ending | 멀티 엔딩 |
| 💾 Save | 데이터 저장 |
| 🎵 Sound | 배경음악 및 효과음 |
