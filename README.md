## 📖 프로젝트 소개

**Stella**는 별을 매개로 여러 이야기를 경험하는  
스토리 중심의 Android 개인 프로젝트입니다.

플레이어는 화면을 따라 이동하며 별을 선택하고,  
각 별에 담긴 이야기를 확인한 뒤 결과와 엔딩에 도달합니다.

> **“한 편의 이야기를 직접 플레이한다.”**

라는 경험을 목표로 제작했습니다.

---

```text
Main

  ↓
Result

Ending
```

## ✨ 주요 기능

- 별 선택을 통한 이야기 진입
- 화면 전환에 따른 순차적인 스토리 진행
- 선택 결과를 반영한 결과 화면
- 스토리 종료 후 엔딩 화면 제공
- Android 환경에 맞춘 세로형 UI 구성
